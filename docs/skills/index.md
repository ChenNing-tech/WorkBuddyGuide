# Skill 技能：把经验变成可重复执行的能力

提示词解决一次任务，Skill 用来稳定复用一类任务。它通常包含适用场景、输入要求、操作步骤、质量标准、边界与必要资源。

## 什么时候值得做成 Skill

- 同一类任务已经重复做过三次以上
- 过程有稳定步骤，不完全依赖临场判断
- 输出有明确质量标准
- 需要固定检查隐私、事实或格式
- 希望把方法分享给同事继续使用

## 制作流程

1. 收集一条已经跑通的真实任务记录。
2. 区分固定步骤与每次变化的输入。
3. 写清触发条件、所需材料和预期输出。
4. 加入事实核验、人工确认与失败处理。
5. 用至少三个不同样例测试，不只测试理想输入。
6. 记录版本、适用范围与已知限制后再分享。

## Skill 说明骨架

```markdown
# Skill 名称

## 适用场景
什么时候使用，什么时候不要使用。

## 输入
需要哪些文件、背景信息与用户选择。

## 流程
1. 检查材料
2. 明确目标
3. 分阶段执行
4. 验证结果

## 输出标准
格式、准确性、完整性与可编辑性要求。

## 安全边界
敏感信息、外部发送、人工复核与失败处理。
```
