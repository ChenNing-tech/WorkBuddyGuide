# 6. 成长与科研

## 6.1 成长中心

成长中心适合记录教师个人学习计划、阶段目标和学习成果。

- 按方向建立计划，例如教学能力、信息化能力或专业认证。
- 把长期目标拆成阶段和任务，持续记录进度与笔记。
- 有明确日期或时间的学习计划会进入个人效率日程。

![成长中心与学习计划](/teacher-assistant/image19.jpeg)

## 6.2 科研管理

科研管理用于跟踪论文、课题、成果和关键节点，帮助把科研事项纳入日常任务。

- 按项目或成果建立记录，填写阶段、状态、截止时间和备注。
- 定期更新进展，将近期节点转为待办并设置提醒。
- 归档材料时建议使用统一命名，并在文件管理中建立关联。
