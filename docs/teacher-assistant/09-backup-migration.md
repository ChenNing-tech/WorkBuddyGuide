# 9. 备份、恢复与迁移

## 9.1 数据保存位置

| 目录 / 文件 | 用途 |
| --- | --- |
| `data/teacher_assistant.db` | 主要业务数据库 |
| `uploads/` | 上传的附件和资料 |
| `imports/` | 导入过程文件 |
| `backups/` | 系统生成的数据库备份 |
| `exports/` | 导出的文件 |
| `logs/` | 运行日志，用于排查问题 |

## 9.2 创建与恢复备份

1. **创建备份**：进入设置页的数据维护区域，点击创建数据库备份。
2. **保存副本**：将 `backups` 中的备份和 `uploads` 附件目录复制到移动硬盘或学校认可的安全位置。
3. **恢复数据库**：在设置页上传 `.db` 备份文件。系统会先自动备份当前数据库，再执行恢复。
4. **核对附件**：恢复后检查文件能否打开；若缺失，补回与数据库同时备份的 `uploads` 文件夹。

::: tip 建议的备份频率
日常使用可每周备份一次；批量导入课表、学生、课程或大量附件前，再额外创建一次备份。
:::

## 9.3 迁移到另一台电脑

1. 先关闭程序，复制整个 `TeacherWorkAssistant` 文件夹。
2. 在新电脑上启动 `TeacherWorkAssistant.exe`，并检查课程、学生、通知和附件。
3. 不要只复制数据库，也不要只复制 EXE；两种方式都可能造成附件或运行依赖缺失。
