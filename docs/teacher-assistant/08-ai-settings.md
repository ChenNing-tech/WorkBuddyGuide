# 8. AI 功能与设置

## 8.1 分享版默认状态

分享版不包含制作者的 API 地址、模型或 API Key，在线 AI 默认关闭。未配置 API 时，通知辅助整理等支持本地规则的功能仍可按本地模式工作。

## 8.2 配置步骤

| 设置项 | 文档中的建议值 |
| --- | --- |
| 启用 | 勾选 AI 接口 |
| 服务商名称 | DeepSeek |
| API Base URL | `https://api.deepseek.com` |
| API Key | 在 DeepSeek 开放平台创建；首次填写时使用“重新输入 API KEY” |
| 模型名称 | `deepseek-v4-flash` 或 `deepseek-v4-flash-vision-exp` |
| Temperature | `0.3` |
| Max Tokens | `4000` |
| 请求超时 | 90 或 120 秒 |

![设置页中的 AI 接口区域](/teacher-assistant/image23.png)

配置完成后点击“保存 AI 配置”，再点击连接测试。出现连接成功提示，说明接口已经接入。

1. **确认服务来源**：向学校信息部门或可信服务提供方获取接口地址、模型名和个人密钥。
2. **填写并保存**：在设置页开启在线 AI，填写参数并保存；页面显示密钥时会进行脱敏。
3. **小范围测试**：先用不含学生隐私的普通内容测试连通性和输出质量。
4. **教师复核**：AI 生成的任务、摘要、答复和阅卷结果必须由教师确认后再使用。

::: warning 参数以服务商当前说明为准
模型名称和接口能力可能调整。若文档中的示例名称不可用，请以服务商控制台和官方文档显示的可用模型为准。
:::

::: danger 何时会把内容发送到外部服务
只有使用者主动启用并配置 AI API 后，AI 相关请求才会发送到所配置的服务地址。普通任务、课程、学生、通知和本地文件管理不会因此自动上传。不要将学生隐私或学校敏感信息直接发送给未经批准的外部 AI 服务。
:::
