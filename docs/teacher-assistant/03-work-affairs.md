# 3. 工作事务

## 3.1 通知管理

通知管理采用“左侧列表 + 右侧详情”结构，适合连续浏览和处理校内通知。

- **顶部统计**：全部、未处理、今天截止、本周截止、带附件。
- **筛选条件**：关键词、来源、类型、状态及截止日期。
- **列表信息**：标题、来源、发布时间、截止时间、状态和附件标识。
- **处理动作**：转为待办、标记处理中、标记完成。

![通知管理列表与筛选区](/teacher-assistant/image8.jpeg)

推荐先筛选“未处理”，优先查看重要或即将截止的通知；阅读正文和附件后，再决定转为待办或标记完成。

![通知详情、正文、附件与关联任务](/teacher-assistant/image9.jpeg)

::: info 转为待办不会删除通知
系统只新增一条关联任务，并保留原通知记录，便于后续追溯来源、附件和处理状态。
:::

## 3.2 会议管理

会议管理按时间线组织会议，右侧集中展示概览、会前准备、会议纪要和会后事项。

- 顶部统计：今天会议、本周会议、待整理纪要、会后待办。
- 可按主题、组织者、参会人、类型、状态和日期范围筛选。
- 左侧时间线按日期和时间排列，点击会议即可切换右侧详情。
- 概览中可查看主题、日期、时间、地点、形式、组织单位、参会人员、议程与附件。
