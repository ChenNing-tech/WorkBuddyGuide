# 7. 资源中心

## 7.1 文件管理

- 文件管理用于登记、上传、搜索和关联教学资料、通知或会议附件。
- 上传时填写标题、分类、标签和关联对象，后续更容易检索。
- 移动程序或恢复数据库时，`uploads` 文件夹需要与数据库一起保留。
- 删除记录前先确认文件是否仍被课程、通知或会议使用。

![文件管理与资料检索](/teacher-assistant/image21.jpeg)

## 7.2 常用网站与教师工具箱

常用网站用于收藏校内平台和教育资源，教师工具箱用于登记 OCR、PDF、截图、压缩等本地或在线工具。

- 首页只保留高频快捷入口，完整工具目录在教师工具箱中查看。
- 外部网站和工具由各自服务提供，首次使用时注意账号权限和文件隐私。
