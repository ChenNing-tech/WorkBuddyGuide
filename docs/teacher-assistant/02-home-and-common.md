# 2. 首页与通用操作

## 2.1 认识首页

首页用于快速判断“今天要做什么、有什么变化、从哪里开始”，建议将它作为每天的第一站。

- **欢迎区**：显示问候、日期、课程提示和当前学期状态。
- **状态条**：待办、课程、跟进、通知、关注学生均可点击进入对应模块。
- **今天时间线**：聚合今日课程、会议、有明确时间的任务和截止事项。
- **待办与最近通知**：支持快速完成、查看全部或进入通知详情。
- **右侧概览**：展示本周进度、学期驾驶舱和高频快捷入口。

![首页三栏布局与主要入口](/teacher-assistant/image1.jpeg)

::: info 首页只负责快速进入
通知编辑、课程维护、学生资料修改等完整操作仍在对应模块进行。首页以查看和快速动作优先。
:::

## 2.2 搜索、提醒与主题

- 顶部搜索框可查找功能、文件、学生和通知等内容。
- 通知铃铛显示未处理提醒；点击后按提示进入相关详情。
- 主题按钮用于切换界面风格，布局和操作逻辑保持一致。
- 头像区域用于查看当前教师资料；需要修改时前往设置。

## 2.3 快捷入口

- 默认入口面向高频教学动作，包括新增待办、录入出勤、随机点名、上传资料、OCR 识别和专注计时。
- 点击“自定义”可从现有功能中固定最多 6 个入口。
- 取消自定义不会保存临时改动；确认后首页会立即更新。
- “全部工具”进入教师工具箱，PDF 等低频工具集中在那里。
