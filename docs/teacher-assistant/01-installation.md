# 1. 安装与首次启动

## 1.1 安装客户端

1. 双击 `TeacherWorkAssistant_Setup_*.exe`。若 Windows 提示安全确认，请核对安装包来源后继续。
2. 按安装向导选择安装位置并完成安装，建议保留默认文件夹结构。
3. 从开始菜单打开“教师工作管理助手”。程序会启动本地服务并自动打开浏览器。

![安装位置选择界面](/teacher-assistant/image3.png)

*安装路径可以手动修改至 D 盘、E 盘等。*

![创建桌面快捷方式](/teacher-assistant/image4.png)

*可按需要创建桌面快捷方式。*

## 1.2 打开与退出

- 默认地址通常为 `http://127.0.0.1:8000`。若端口被占用，程序会自动尝试 8001 至 8005。
- 浏览器没有自动打开时，请查看控制台窗口显示的实际地址并手动访问。
- 退出时关闭 `TeacherWorkAssistant.exe` 的控制台窗口；下次从开始菜单重新启动。

![从开始菜单启动教师工作管理助手](/teacher-assistant/image5.png)

*在开始菜单或桌面双击快捷图标，工具会自动运行并打开浏览器。*

![教师工作管理助手首页](/teacher-assistant/image6.png)

::: warning 不要只移动 EXE 文件
数据库、上传文件、导入文件、备份和日志都在程序同级目录。复制或迁移时应保留整个 `TeacherWorkAssistant` 文件夹。
:::

## 1.3 首次设置

1. 进入左侧“设置”，填写姓名、学院、职称等基础资料。
2. 选择常用主题；各主题只改变视觉呈现，不改变业务数据。
3. 确认学期、开学日期和周数，课表及首页学期进度会据此计算。
4. 暂不使用在线 AI 时保持关闭即可，不影响任务、课程、学生、通知等本地功能。
