# 4. 个人效率

个人效率将日历、日程、待办、习惯和专注计时放在同一页，适合处理日常工作节奏。

## 4.1 日历与日程

- 使用左右箭头切换月份，点击“今天”回到当前日期。
- 有事项的日期显示圆点；今天和当前选中日期采用不同高亮。
- 当日日程会整合课程、会议、有明确时间的待办、截止事项和学习计划。

## 4.2 待办任务

- 按“今日、本周、全部、已完成”切换列表。
- 快捷输入标题后按回车即可新增；需要完整字段时打开任务编辑弹窗。
- 完成后任务会更新进度并进入已完成分类，提示出现时可撤销。
- 任务可填写日期、开始时间、截止时间、分类、优先级、备注、提醒和重复规则。

## 4.3 习惯与专注计时

- 习惯打卡支持新增、编辑、停用、删除、今日打卡和取消打卡。
- 系统显示连续完成天数、最近 7 天记录和每周完成率。
- 专注计时支持 25、45、60 分钟等模式，可关联当前任务。
- 切换页面后计时状态会保留；计时完成后记录专注时长并尝试发送 Windows 通知。
