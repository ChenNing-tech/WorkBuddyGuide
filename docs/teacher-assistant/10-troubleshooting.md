# 10. 常见问题

| 现象 | 处理建议 |
| --- | --- |
| 双击后没有反应 | 检查是否被 Windows 安全策略拦截；核对安装来源后，可尝试右键以管理员身份运行。 |
| 浏览器没有自动打开 | 查看程序控制台中的实际地址，在浏览器中手动访问。 |
| 8000 端口被占用 | 程序会自动尝试 8001 至 8005，以控制台显示的地址为准。 |
| 页面样式或模板丢失 | 确认程序文件夹完整，未只移动 EXE 文件；必要时重新安装。 |
| 上传的文件打不开 | 确认 `uploads` 文件夹仍在，并与数据库来自同一次备份或迁移。 |
| 恢复后记录在但附件不在 | 数据库恢复不等于附件恢复，请补回对应的 `uploads` 文件夹。 |
| AI 接口连接失败 | 检查 Base URL、API Key、模型名称、网络和代理；先用非敏感内容测试。 |
| 专注计时没有系统提醒 | 允许浏览器通知，检查 Windows 通知和专注助手设置，并保持客户端运行。 |
| 首页数据与预期不一致 | 检查当前学期、日期、任务截止时间、通知状态和课表周次是否正确。 |

## 问题反馈前请准备

- 当前使用的客户端版本和 Windows 版本。
- 控制台或 `logs` 目录中对应时间的错误信息。
- 问题出现前执行了哪些步骤，以及是否能稳定复现。
- 脱敏后的页面截图；不得包含 API Key、学生隐私或学校敏感信息。
