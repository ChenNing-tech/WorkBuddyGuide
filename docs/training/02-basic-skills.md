# AI 基础能力

AI 结果是否可用，通常取决于任务是否说清楚。与其反复要求“再专业一点”，不如在开始时明确五个问题。

## 五个任务要素

| 要素 | 需要说明什么 | 教师场景示例 |
| --- | --- | --- |
| 目标 | 这项任务要解决什么问题 | 为下周公开课准备教学活动方案 |
| 受众 | 谁会阅读或使用结果 | 面向同年级备课组老师 |
| 材料 | 哪些文件是事实来源 | 课程标准、教材片段和活动要求 |
| 格式 | 最终交付物是什么 | Word 方案、Excel 分工表、PPT 汇报 |
| 验收 | 怎样判断结果可以使用 | 内容可追溯、时间合理、格式可编辑 |

## 通用任务模板

```text
请根据我提供的材料完成一项任务。

目标：
受众：
事实来源：
需要输出：
必须保留：
不能编造：
验收标准：

请先检查材料是否完整，并列出缺失信息。没有确认的信息标记为“待确认”。
```

## 自主练习

把下面这条模糊指令改写成可执行任务：

```text
帮我做一份公开课方案，要专业一些。
```

改写时至少补充：

1. 学科、年级和课题。
2. 公开课的目标与听课对象。
3. 可以使用的教材或课程标准。
4. 需要的文件类型和内容结构。
5. 哪些事实不能由 AI 自行补充。
6. 最终由谁检查以及如何验收。

## 二次修改方法

对初稿不满意时，不要只说“重新写”。指出差异更容易得到稳定结果：

```text
请在上一版基础上修改，不要重写全部内容。

修改要求：
1. 保留原有教学目标。
2. 将课堂活动压缩为三个环节。
3. 每个环节补充教师行为、学生活动和预计时间。
4. 删除没有材料依据的案例。
5. 在结尾列出仍需人工确认的问题。
```

## 结果验收

检查 AI 结果时至少回答：

- 关键事实能否回到原始材料？
- 是否把猜测写成了确定结论？
- 结果是否真正面向指定受众？
- 文件是否可编辑，结构是否完整？
- 是否存在不适合学生年龄、学科或课堂条件的内容？
- 下一位老师是否能看懂并继续修改？
