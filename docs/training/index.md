# 教师 AI 培训专区

这里是一条可以直接用于现场培训的学习路径。老师不需要先记住所有功能，而是从一个真实任务开始，完成操作、检查结果，再把有效方法保存下来。

::: tip 培训目标
完成本次培训后，老师能够把一个模糊需求改写成可执行任务，使用 AI 辅助处理文档、表格和汇报材料，并对事实、格式、隐私与教学适切性进行人工复核。
:::

## 建议培训流程

1. 完成课前准备，确认设备、材料和安全边界。
2. 学会描述 AI 任务并设置验收标准。
3. 完成一次 Word、Excel、PPT 综合练习。
4. 把方法迁移到备课、评价或教研场景。
5. 复盘操作过程并保存可复用模板。

## 现场学习约定

1. 使用练习材料，不上传真实学生敏感信息。
2. 每项任务先说清交付标准，再让 AI 执行。
3. AI 生成的事实、数据、引用和评价必须由人检查。
4. 记录有效指令和修改过程，不只保存最终文件。
5. 遇到不确定内容时标记“待确认”，不让 AI 自行补全事实。

## 讲师建议

- 演示时先展示一条过于模糊的指令，再现场补齐任务要素。
- 每个模块至少留出一次学员独立操作和一次同伴互查。
- 现场重点不是比较谁生成得更快，而是比较谁的结果更可靠、更容易复用。
- 培训结束前，让每位老师带走一个与自己学科相关的模板。
