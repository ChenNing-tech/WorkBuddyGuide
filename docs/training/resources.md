# 可复用资源

本页内容可以直接复制到 AI 工具中，再根据具体学科、材料和任务进行修改。

## 通用任务模板

```text
请根据我提供的材料完成以下任务。

目标：
受众：
事实来源：
需要输出：
必须保留：
不能编造：
验收标准：

请先检查材料是否完整，说明可用信息、缺失信息和可能风险。没有确认的信息标记为“待确认”。等我确认大纲后再生成最终文件。
```

## 二次修改模板

```text
请在上一版基础上修改，不要重新生成全部内容。

需要保留：
需要删除：
需要补充：
格式调整：
语气调整：
验收要求：

完成后列出本次实际修改内容和仍需人工确认的问题。
```

## 材料检查模板

```text
请先不要生成最终结果。

读取当前工作区材料后，输出：
1. 文件清单及各自用途。
2. 可以作为事实来源的材料。
3. 仅能作为格式参考的材料。
4. 缺失、矛盾或无法确认的信息。
5. 涉及个人信息、版权或发布权限的风险。
6. 建议的任务步骤和人工确认点。
```

## 结果验收模板

```text
请检查刚生成的结果，不要直接修改。

按以下类别列出问题：
1. 与原始材料不一致的事实。
2. 缺少来源或无法确认的内容。
3. 人名、日期、数量和责任主体问题。
4. 结构、格式和可编辑性问题。
5. 教学适切性与安全边界问题。

为每个问题说明位置、影响和建议修改方式。
```

- [ ] 进行一次明确的二次修改。
- [ ] 使用验收模板检查结果。
