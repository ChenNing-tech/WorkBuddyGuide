# 办公三件套实践

本模块使用同一组事实材料，生成 Word、Excel 和 PPT。这样可以避免三个文件各写一套口径，也方便检查数字、人员和时间是否一致。

## 练习场景

学校准备开展一次校内 AI 教学应用交流活动。你需要根据讲师提供的活动说明和人员安排，形成一套可以继续修改的办公交付包。

## 任务指令

```text
请读取当前练习工作区中的活动说明和人员安排，先不要修改原文件。

目标：为校内 AI 教学应用交流活动准备一套可执行的办公材料。
受众：活动负责人、参与教师和学校管理人员。

请输出：
1. output/activity-plan.docx，包含活动目标、对象、流程、人员分工、物料、风险和待确认问题。
2. output/action-items.xlsx，字段包含事项、负责人、截止时间、依赖、状态和验收标准。
3. output/briefing.pptx，控制在适合短时汇报的篇幅，突出目标、流程、分工、风险和需要确认的事项。

要求：
1. 人名、日期和数量只能来自原始材料。
2. 缺少的信息标记为“待确认”。
3. 三个文件使用同一套时间和人员口径。
4. 文件必须可编辑。
5. 先输出材料检查结果和内容大纲，等我确认后再生成文件。
```

## Word 检查

- 标题层级清楚，没有重复章节。
- 活动目标与流程对应。
- 人员、日期和地点来自原始材料。
- 风险部分包含处理责任人和备用方案。
- 没有把“建议”写成已经批准的决定。

## Excel 检查

- 每一项任务都有负责人或明确标记“待确认”。
- 日期格式统一，截止时间可以排序。
- 状态字段使用固定选项，不混用近义词。
- 汇总结果能够回到原始行。
- 异常项没有被静默删除。

## PPT 检查

- 每页只表达一个主要结论。
- 管理人员最关心的决定、资源和风险放在前面。
- 关键人员、时间和数量与 Word、Excel 一致。
- 投屏后字号可读，没有文字或图片溢出。
- 不使用没有来源的装饰性数据和结论。

## 同伴互查

两位老师交换结果，分别检查：

1. 是否能从原始材料找到关键事实。
2. 三个文件中的日期、人员和任务是否一致。
3. 哪些内容仍然需要负责人确认。
4. 是否存在可以删除的空话或重复内容。
