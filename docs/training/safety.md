# 安全与使用边界

本页用于培训现场的统一安全说明。学校的正式制度和所使用工具的隐私条款优先于本页内容。

## 上传前先判断

| 材料类型 | 建议处理方式 |
| --- | --- |
| 公开课程标准、公开政策和自编练习材料 | 确认来源后可以使用 |
| 脱敏后的示例成绩或课堂记录 | 仅在无法还原学生身份时使用 |
| 学生姓名、联系方式、证件信息 | 不上传 |
| 成绩、健康、心理、家庭情况 | 未经明确授权不上传 |
| 学校内部账号、密码、密钥 | 不上传 |
| 未公开试题、合同和内部会议材料 | 按学校规定和授权处理 |
| 教材、论文、图片等版权内容 | 确认授权范围，不要求 AI 大段复现 |

## 最小授权原则

- 只把完成任务需要的文件放入工作区。
- 只授权 AI 访问当前练习目录。
- 修改或覆盖文件前先保留原件。
- 涉及发送、发布、删除或批量修改时，先确认目标和范围。
- 不把个人账号或学校系统凭据写入提示词和文档。

## 必须人工复核的内容

- 学科事实、计算过程、答案和引用。
- 学生评价、分层建议和个别化反馈。
- 对学生可能产生重要影响的决定。
- 对外发布的通知、新闻和正式材料。
- 涉及法律、健康、心理和安全的判断。

## 现场安全口令

讲师可以在每项练习开始前提醒：

```text
先看材料能不能上传，再看任务是否说清楚，最后检查结果能不能负责。
```

## 出现问题时

如果误上传了不应上传的材料：

1. 立即停止当前任务。
2. 按工具提供的方式删除相关会话或文件。
3. 不继续复制、转发或截图传播。
4. 按学校的信息安全流程报告。
5. 记录发生原因并修改后续培训材料和操作要求。
