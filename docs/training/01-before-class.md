# 课前准备

课前准备的目标是让老师到场后能够直接开始练习。讲师可以在培训前一天发送本页链接，并提醒学员逐项确认。

## 设备与软件

- 一台可以正常联网的电脑。
- 推荐使用 Chrome 或 Edge 浏览器。
- 已安装本次培训指定的 AI 工具。
- 已安装 Microsoft Office 或 WPS，用于打开和检查生成文件。
- 电脑中有一个专门用于本次培训的练习文件夹。

建议创建以下目录：

```text
教师AI培训/
├─ input/       原始练习材料
├─ output/      AI 生成结果
├─ prompts/     有效指令与修改记录
└─ review/      人工检查与反馈
```

## 账号检查

1. 提前登录本次培训使用的 AI 工具。
2. 确认账号能够新建任务并上传练习文件。
3. 如果工具需要读取本地工作区，只授权培训练习目录。
4. 不要把整个桌面、个人文档或学校共享盘作为练习工作区。

## 练习材料

为了避免现场处理真实敏感数据，建议讲师准备一套虚构或脱敏材料：

- 一份课程或活动说明文本。
- 一张不包含真实学生身份信息的示例数据表。
- 一份需要改进的旧版汇报大纲。
- 一份明确的培训任务单。

## 开始前的安全检查

在上传任何文件前，先确认文件中不包含：

- 学生姓名、证件号码、家庭住址和联系方式。
- 未公开的成绩、健康信息、心理记录或家庭情况。
- 学校账号、密码、密钥和内部系统地址。
- 未经授权的试题、合同、会议材料或版权内容。

如果无法判断是否可以上传，先停止操作并询问学校相关负责人。更多说明见[安全与使用边界](./safety.md)。

## 课前验收

完成以下检查后再进入下一模块：

- [ ] 可以正常登录 AI 工具。
- [ ] 已创建独立练习文件夹。
- [ ] 已下载并打开练习材料。
- [ ] Office 或 WPS 可以正常打开文件。
- [ ] 了解哪些材料不能上传。
